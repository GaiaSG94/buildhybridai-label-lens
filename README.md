# Label Lens

Photo of a packaging label -> Gemini Nano reads the image **on device** and extracts
ingredients, allergens, nutrition and warnings; the cloud only recoups what the local
pass could not read. Every field shows its source (LOCAL / CLOUD).

buildhybridai-2026 / Grand Prize. Ideation: `IDEE.md`. Design brief: `PROMPT-DESIGN.md`.
